# Existing CDM provider integration

This directory contains the pre-existing executable provider/evidence-backed CDM eligibility integration. It is independent of the [new FINOS CDM collateral-eligibility contribution scaffold](../contributions/finosCdm/collateralEligibility/README.md). Provider response transport verification and existing assessment outcomes do not validate the authoritative requirement, CDM mappings, or source provision for the new contribution. Existing functionality is preserved.
